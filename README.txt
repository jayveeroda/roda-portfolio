HOW TO USE
----------
1. Put your portrait at:
   images/profile.png

2. Put your project screenshots or GIFs in the images folder. Project popup
   content and media paths are stored in the projectDetails section of script.js.
   Projects without public screenshots automatically use a private placeholder.

3. Change email/social links in index.html:
   - your@email.com
   - LinkedIn URL
   - GitHub URL

4. Open index.html in your browser.

5. For GitHub Pages:
   - Upload index.html, style.css, script.js, and the images folder.
   - Keep all file/folder names lowercase exactly as referenced.
